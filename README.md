# PersianCalendarWatch

تقویم شمسی فارسی برای Samsung Galaxy Watch Active2 (Tizen).

## امکانات نسخه پایه
- نمایش تاریخ شمسی روز جاری
- نام روز هفته و ماه شمسی
- اعداد فارسی
- تبدیل میلادی به شمسی به صورت آفلاین
- معماری آماده برای Widget
- بدون نیاز به اینترنت

## Roadmap
- ویجت اختصاصی و بهینه برای صفحه گرد Active2
- تقویم ماهانه شمسی
- مناسبت‌های رسمی ایران
- تعطیلات رسمی
- تنظیمات فونت و اندازه
- نمایش ساعت و تاریخ در یک صفحه
- به‌روزرسانی خودکار هنگام تغییر روز

## پلتفرم
Tizen Wearable / Galaxy Watch Active2
