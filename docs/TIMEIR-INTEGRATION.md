# اتصال تقویم به Time.ir

منبع رسمی داده‌های تقویم این پروژه **Time.ir** است.

Time.ir در صفحه تقویم، تاریخ خورشیدی، میلادی و قمری و همچنین مناسبت‌های ماه را نمایش می‌دهد؛ صفحه تقویم سالانه نیز مناسبت‌های سال را ارائه می‌کند. این پروژه از همین منبع برای داده‌های تقویم استفاده می‌کند.

## معماری

ساعت نباید برای نمایش تاریخ روزانه به اینترنت وابسته باشد. بنابراین:

1. ابزار `tools/timeir_sync.py` روی سیستم توسعه یا CI اجرا می‌شود.
2. داده‌های مناسبت‌ها از Time.ir دریافت و به JSON تبدیل می‌شوند.
3. JSON داخل برنامه بسته‌بندی می‌شود.
4. ساعت تاریخ و مناسبت‌ها را به صورت آفلاین نمایش می‌دهد.

## چرا اتصال مستقیم ساعت به Time.ir نداریم؟

Galaxy Watch Active2 باید بتواند تقویم را حتی بدون اتصال اینترنت نشان دهد. همچنین scrape کردن HTML در خود ساعت پرهزینه و شکننده است. به همین دلیل Time.ir را **منبع داده** قرار می‌دهیم، نه یک وابستگی لحظه‌ای در UI.

## به‌روزرسانی

با اجرای زیر داده جدید تولید می‌شود:

```bash
python tools/timeir_sync.py
```

سپس فایل داده در repository commit می‌شود و نسخه جدید برنامه/ویجت ساخته می‌شود.

## نکته حقوقی

داده‌های Time.ir باید مطابق شرایط استفاده و حقوق مالکیت محتوای همان سرویس استفاده شوند. این پروژه منبع داده را شفافاً Time.ir معرفی می‌کند و منطق نمایش/رابط کاربری متعلق به این پروژه است.
