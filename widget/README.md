# ویجت تقویم شمسی

ویجت برای نمایش سریع تاریخ شمسی روی Galaxy Watch Active2.

## نمایش
- روز شمسی
- نام ماه
- سال
- وضعیت تعطیل/مناسبت در صورت وجود داده

## طراحی
ویجت باید سبک باشد و با صفحه گرد Active2 سازگار بماند. منطق تقویم از هسته اصلی برنامه استفاده می‌کند و هیچ درخواست شبکه‌ای از خود ساعت انجام نمی‌دهد.

## Tizen
این کد برای تبدیل به Tizen Native Widget آماده‌سازی شده است. در مرحله بسته‌بندی، Widget و Application با manifest و certificate سازگار با نسخه Tizen دستگاه بسته‌بندی می‌شوند.
